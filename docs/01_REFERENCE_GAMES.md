# Reference Games: Tile Match & Mahjong Category

---

## Reference Game 1: Vita Mahjong

### 1. Basic Information
* **Developer / Publisher:** Vita Studio
* **Platform:** iOS, Android
* **Genre:** Mahjong Solitaire / Senior Brain Game
* **Release Period:** 2023 – Present
* **Scale / Downloads:** 126 Million+ downloads (#1 fastest-growing senior puzzle game globally)
* **Game Type:** Large-format Mahjong Solitaire Pair Matching

### 2. Core Gameplay
* **What the player does:** Taps 2 identical unblocked Mahjong tiles to match and clear them.
* **What the player sees:** Oversized traditional and modern tile sets, high-contrast layouts, soft pastel backgrounds.
* **Decisions made:** Choosing which edge-pairs to clear first to open access to buried tiles.
* **Constitutes success:** Clearing all tiles from the board.
* **Constitutes failure:** No more legal pairs available on the exposed layers (requires reshuffle or undo).
* **What happens after success:** Gentle celebratory chime, garden / scenery collection trophy.
* **What happens after failure:** Prompt to watch an ad for a free reshuffle.

### 3. Gameplay Loop
```text
PLAYER ACTION (Tap 2 Unblocked Matching Tiles)
       ↓
GAME RESPONSE (Pair Dissolves with Soft Sound; Lower Layer Tiles Unblocked)
       ↓
REWARD / CONSEQUENCE (Points Added & Board Complexity Reduces)
       ↓
PROGRESSION (Clear Entire Board -> Unlock New Sanctuary Theme)
       ↓
NEXT CHALLENGE (Higher Stacking Complexity & Deeper Layers)
```

## Reference Game 2: Tile Club

### 1. Basic Information
* **Developer / Publisher:** Gameduell
* **Platform:** iOS, Android
* **Genre:** 3D Tile Matching / 3-Tile Holding Tray Solitaire
* **Release Period:** 2022 – Present
* **Scale / Downloads:** 88 Million+ downloads
* **Game Type:** Staged 3-Tile Match with 7-Slot Tray Buffer

### 2. Core Gameplay
* **What the player does:** Taps exposed tiles from a 3D isometric stack. Each tapped tile drops into a 7-slot holding tray at the bottom.
* **What the player sees:** Colorful porcelain tiles stacked in multi-layered pyramid or animal shapes.
* **Decisions made:** Managing tray space carefully so it does not fill with 7 disparate tiles before forming triads.
* **Constitutes success:** Clearing all stacked tiles through forming 3-of-a-kind sets.
* **Constitutes failure:** Tray fills with 7 mismatched tiles, resulting in game over.
* **What happens after success:** Level completed fanfare, stars awarded.
* **What happens after failure:** Screen shake, offer to spend coins or watch video ad to undo.

### 3. Gameplay Loop
```text
PLAYER ACTION (Tap Unblocked Tile from 3D Stack)
       ↓
GAME RESPONSE (Tile Drops into 7-Slot Tray; Matches Triad if 3 Present)
       ↓
REWARD / CONSEQUENCE (Triad Disappears, Freeing 3 Tray Slots)
       ↓
PROGRESSION (Excavate Deeper Layers)
       ↓
NEXT CHALLENGE (Narrower Tray Margin & Deceptive Stacks)
```
